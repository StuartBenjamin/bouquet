# tests/data

| file | what | used by |
|------|------|---------|
| `d3dlike.geqdsk`, `d3dlike_reference.npz` | synthetic (the D3D-like example) | g-file / reference tests |
| `stored_configs/` | synthetic stored configs | stored-config compatibility tests |
| `apply_sigma_templates.py` | writes every fixture's sigma envelopes from the radial templates (`bouquet.uncertainties.sigma_template`) | `test_fixture_sigma.py` |
| `dd_synthetic.json.gz` | synthetic OMAS/IMAS dd: five equilibrium / core_profiles / core_sources slices (0.7, 1.1, 1.2, 1.4, 3.0 s) of one H-mode-like discharge, from a mid-ramp L-mode through the L-H transition and a hot-ion peak-pedestal phase to a steady flat-top; Ip 0.95 then 1.0 MA, B0 -2.0 T, lower single null | `test_swb_systematics_solver.py`, `test_phi_imas_solver.py`, `test_parallel_cases_solver.py`, `test_solver_reuse_solver.py` (`-m solver`), `test_units.py` |
| `diiid_profs_synthetic.cdf` | IDA-layout fit paired with the dd's 1.2 s slice (sigmas: the ramp radial template) | same |
| `g_synthetic.geqdsk` | the equilibrium that IDA fit belongs to (kinetic-EFIT-like: ohmic + Redl bootstrap current, no beam channel), 1.2 s | same |
| `g_synthetic_lmode.geqdsk`, `ida_synthetic_lmode.cdf` | a second regime: sawtoothing L-mode (q0 0.8), upper single null, Ip 1.3 MA, B0 -2.0 T, with its IDA-layout fit (sigmas: the L-mode radial template) | g-file + IDA workflows (reserved for the real-data ladder's synthetic rung) |

All five IMAS-path files are generated by `make_synthetic_fixtures.py` (owner decision D3): analytic profile families
(`Hmode_profiles`, polynomials) with parameters rounded to two significant figures, every slice re-solved
self-consistently by TokaMaker from its kinetics up (pressure including fast ions, Redl bootstrap on the converged
state, beam and ohmic currents), written in COCOS 11 with `j_tor` built on the previous slice as FUSE does. What each
file carries, what the code reads, and what the dependent tests assert: [`FIXTURE_SPEC.md`](FIXTURE_SPEC.md).
Regenerate with `python tests/data/make_synthetic_fixtures.py OUT_DIR` on a machine with OpenFUSIONToolkit (the
`--mesh` option takes a finer machine mesh for the solves; the fixtures are mesh-independent).

Sigma envelopes: every kinetic sigma (the IDA files' `*_err`, the dd's
core_profiles `*_error_upper` on all five slices) is the 2-s.f. radial template
of the fixture's phase -- the median relative envelopes of IDA-lite deliveries
on DIII-D H-mode flat-top / ramp / L-mode slices -- times the profile
([`FIXTURE_SPEC.md`](FIXTURE_SPEC.md) section 7). `python
tests/data/apply_sigma_templates.py [DIR]` rewrites them in place without a solve
(the profiles are checked unchanged bit for bit); the generator calls the same
functions.
